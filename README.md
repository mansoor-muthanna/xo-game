# Tic-Tac-Toe (X O Game) 🎮

*[🇪🇸 Read in English](#english) | [🇸🇦 اقرأ باللغة العربية](#arabic)*

---

<h2 id="english">English</h2>

A very simple and straightforward Tic-Tac-Toe game built with **C#** and **Windows Forms**. 

This project was created as a fundamental university assignment to practice basic programming concepts (variables, conditional statements, and UI events). It focuses entirely on simplicity and foundational logic without any over-engineering or complex patterns.

### Features
* Simple 2-player offline gameplay (X and O).
* Automatic win and draw detection.
* One-click game reset.

### Technologies
* C#
* Windows Forms (.NET)

<h2 id="arabic">العربية</h2>

لعبة "إكس أو" (Tic-Tac-Toe) بسيطة جداً ومباشرة، تمت برمجتها باستخدام لغة **C#** وتقنية **Windows Forms**.

تم إنشاء هذا المشروع كتكليف جامعي أساسي لتطبيق المفاهيم البرمجية الأولية (المتغيرات، الجمل الشرطية، والتعامل مع أحداث واجهة المستخدم). يركز المشروع كلياً على البساطة والمنطق التأسيسي ولا يحتوي على أي تعقيدات أو تقنيات متقدمة.

### المميزات
* لعب ثنائي (X و O) على نفس الشاشة.
* فحص واكتشاف تلقائي لحالات الفوز أو التعادل.
* زر بسيط لإعادة تشغيل اللعبة.

### التقنيات المستخدمة
* C#
* Windows Forms (.NET)
